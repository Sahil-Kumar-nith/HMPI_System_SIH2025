# HMPI System - Intelligent Sample Discovery

This project is the HMPI (Heavy Metal Pollution Index) intelligent sample filtering and discovery system. It provides advanced search, filtering, and data visualization of water/sample quality data.

---

## Contents

- Advanced real-time search and filtering UI
- Heavy metal concentration analysis
- HPI score calculation and safety status
- Responsive and user-friendly interface

---

## Prerequisites

- Python 3.8 or higher
- Virtual environment tool (`venv` or `virtualenv`)
- Installed dependencies (listed in `requirements.txt`)

---
