CSV Format Requirements

Required Columns:
  • location - Sample location name
  • date - Collection date (YYYY-MM-DD)
  • lead - Lead concentration (mg/L)
  • mercury - Mercury concentration (mg/L)
  • cadmium - Cadmium concentration (mg/L)
  • arsenic - Arsenic concentration (mg/L)
Optional Columns:
  • latitude - GPS latitude
  • longitude - GPS longitude

Upload Tips

  • Ensure CSV headers match exactly
  • Use decimal points for concentrations
  • Date format: YYYY-MM-DD (e.g., 2023-12-25)
  • Remove empty rows before upload
  • Use UTF-8 encoding for special characters
  • Maximum file size is 10MB
